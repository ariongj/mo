# Tote bag 3D configurator

Interactive 3D preview of a non-woven PP tote with side gussets, ultrasonic welds and webbing handles.
Fabric colour, handle colour, print (1-colour or full colour), print size and position, and bag
dimensions can all be changed in the browser.

Open `index.html` in a browser, or view the published page via GitHub Pages.

Built with three.js 0.169 (loaded from jsDelivr). No build step.
